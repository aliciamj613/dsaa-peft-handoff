# dsaa_peft_repo

This repository contains the cleaned handoff version of the DSAA PEFT project.

## Included
- configs/
- manifests/
- scripts/
- data/gsm8k
- data/dialogsum
- data/squad_v2
- results/main
- results/main_summary_144.csv
- results/main_summary_144_mean_std.csv
- results/main_summary_144_best_fixed.csv

## Not included
- outputs/
- outputs_72/
- logs/
- results_backup/
- checkpoints / optimizer states / adapter weights

## Main result files
- results/main_summary_144.csv
- results/main_summary_144_mean_std.csv
- results/main_summary_144_best_fixed.csv

## Notes
This repo is for code review, result inspection, and rerunning the project with the provided scripts and data layout.
Large checkpoints and temporary experiment artifacts were intentionally excluded.
